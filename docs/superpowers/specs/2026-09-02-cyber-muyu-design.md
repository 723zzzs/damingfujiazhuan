# 赛博木鱼（Cyber Muyu）· 游戏设计文档

- 日期：2026-09-02
- 状态：已批准
- 类型：抖音小游戏 · Cocos 引擎 · 先做 HTML5 可玩原型

## 1. 游戏定位

**赛博木鱼**是一款竖屏赛博朋克风格的"电子木鱼解压"小游戏，定位抖音休闲/养成品类。核心体验是"闲着无聊点几下"：玩家敲击赛博木鱼积累功德、撑开金光罩抵御鬼物潮，猫与鹦鹉宠物自动协战。视觉 = 传统佛家法器 × 赛博朋克（金 + 青 + 霓虹紫），音色 = 赛博混音版木鱼"咚"。

## 2. 核心玩法

### 2.1 基本布局（竖屏 9:16）

- 木鱼位于屏幕**下方中央**，是唯一主交互位，周身赛博金光护罩
- 金光罩内驻玩家角色（开局选择性别）+ 两只猫 + 四只鹦鹉
- 顶部功德条（分段金色 + 电流描边）+ 等级/鬼物标识 + 图鉴/皮肤/签到入口
- 鬼物从四面八方向金光罩靠拢

### 2.2 核心循环

孤魂野鬼从四周逼近金光罩 → 玩家敲木鱼（+功德、迸发电弧）→ 金光罩随每次敲击绽放脉冲击退/秒杀近身鬼物 → 鬼物血量归零化为**赛博烟花飞天炸开（约 1/3 屏）** → 功德条满 → 木鱼升级 → 鬼物赛博进化 + 新等级鬼登场 + 背景切换。

### 2.3 失败与重生闭环

- 鬼物可以伤害金光罩（消耗罩强度），**功德归零 → 金光罩消失**
- 罩消失后鹦鹉先替玩家死亡（4 只），再猫（2 只），共 **6 次替死**；每次宠物牺牲金光罩重新点亮
- 6 宠全灭 → 弹结算卡（本局功德/击杀/木鱼等级）→ 可选**看激励视频复活 6 宠**继续，否则**重开**
- 重开：宠物复活满编、木鱼回 1 级、功德重蓄；唯一永久保留 = **图鉴**
- 牺牲的宠物化为新鬼种"猫鬼 / 鹦鹉鬼"加入鬼物阵营并录入图鉴

### 2.4 鬼物等级与赛博进化（双维成长）

- 鬼物 9 级：孤魂 → 野鬼 → 厉鬼 → 鬼将 → 鬼仙 → 鬼王 → 判官 → 阎罗 → 鬼佛
- 每级 = 本级新鬼 + 低级鬼赛博化复出，全部形态入图鉴：

| 木鱼等级 | 刷出鬼物 |
|---|---|
| 1 | 1级孤魂 |
| 2 | 2级野鬼 + 赛博化1级孤魂 |
| 3 | 3级厉鬼 + 赛博化1级孤魂 / 2级野鬼 |
| … | … |
| 9 | 9级鬼佛 + 赛博化1~8级全鬼 |
| 通关后 | 再遇鬼佛阶段 → 解锁**赛博鬼佛**（周目 2） |

- 鬼物随等级提升攻击/移动速度，鬼佛阶段需要玩家高频连点木鱼才将将防住
- 猫/鹦鹉击杀的鬼物，其**灵魂净化后归顺玩家**（发光温和友方鬼灵），协同作战，下个等级后消散

### 2.5 宠物系统

- **两只猫**：开局即有攻击能力，随木鱼升级同步进化，赛博改造度逐级升高
- **四只鹦鹉**：木鱼 2/3/4/5 级时逐一解锁攻击，同样随级赛博改造
- 宠物 = **自动索敌攻击**最近的鬼物（玩家专注敲木鱼），一轨点击 + 一轨养宠

### 2.6 数值节奏（第一版可调参数）

| 参数 | 1 级木鱼 | 成长规律 |
|---|---|---|
| 单敲功德 | +10 | 随等级微增（+等级×1） |
| 功德条容量 | 1000 | ×1.8/级 |
| 单敲金光脉冲伤害 | 50 | 技能区域随木鱼升级扩大 |
| 鬼物血量（1级孤魂） | 100 | 每级 ×2.5 |
| 鬼物速度/攻速 | 慢 | 逐级上升，鬼佛需高频连点 |
| 猫伤害 | 30/次，1.2 次/秒 | 随猫等级成长 |
| 鹦鹉解锁 | 木鱼 2/3/4/5 级 | 各解锁 1 只 |

- 功德条节奏选定 **A 慢节奏**：1 级满条 1000 功德，约 5~10 分钟升 1 级，点击频率"闲时点点"

### 2.7 手感与反馈（已选 A + 增强）

- 敲击 = 木鱼实体下沉 + 金色声波圈扩散 + 清脆"咚"（WebAudio 合成赛博木鱼音）+ 数字功德飘字 + 轻微震动
- 敲击额外触发**赛博电流**（随机折线闪电，青色+金色），功德飘字附着电弧
- 鬼物被击 = 火花爆裂声；鬼物死亡烟花为**赛博五颜六色**（青/紫/金/品红多彩粒子）

## 3. 皮肤与商业化

### 3.1 木鱼皮肤（签到固定排期）

- 开局第 1 天签到领第 1 个，之后**每 3 天领下一个**（第 4/7/10…天），皮肤池固定
- 每天签到得不同木鱼外观皮肤（换机身配色/纹路，不改变造型）

### 3.2 鬼物皮肤（广告递进解锁，9 级）

- 第 N 次观看激励视频 → 第 N 级鬼物皮肤 **1 天使用权**（第 1 次=孤魂…第 9 次=鬼佛），1~9 循环（第 10 次=孤魂 1 天…）
- 永久解锁限制 = **累计观看 3N 次广告 + 连续签到 N 天**（孤魂=3 次+连签 1 天，野鬼=6 次+连签 2 天，…，鬼佛=27 次+连签 9 天）
- 鬼物皮肤后续版本继续出新皮肤（预留类型/接口）

### 3.3 广告位

- **激励视频**：宠物全灭复活（6 宠满编）；皮肤试用/永久解锁途径
- 无强制插屏；原型阶段用 3 秒倒计时模拟，`AdProvider` 抽象接口预留，发布时替换抖音 `tt.createRewardedVideoAd()`

### 3.4 图鉴

- 收录：9 级鬼物 + 赛博化形态 + 猫鬼/鹦鹉鬼 + **9 级鬼物皮肤**
- 点亮逻辑：鬼物/形态 = 击杀收集点亮；鬼物皮肤 = **拥有后点亮彩色，未拥有显示黑色阴影剪影**
- 图鉴是重开/周目间唯一永久保留的长期收集目标

## 4. 视觉与音效

### 4.1 赛博风色板

- 背景深墨蓝 `#0a0e17`，赛博青 `#00f0ff`，霓虹紫 `#ff2bd6`，功德金 `#ffd75e`，地狱段加熔岩橙红

### 4.2 画面元素

- 木鱼：深色机身 + 金色电路纹 + 青色能量缝（参考概念图）；皮肤切换仅换配色/纹路
- 金光罩：半透明金色球壳，随强度变化亮度/透明度
- 鬼物：半透明白雾体 + 发光眼；赛博化后附青绿电路纹 + 机械关节；猫鬼/鹦鹉鬼为亡灵暗紫调
- 特效：金光圈扩散（径向渐变环）、赛博电流随机折线、功德飘字带弧光、烟花多彩粒子

### 4.3 背景（8 张赛博地狱 + 1 张灵山）

- 8 种非鬼佛鬼物各对应一张赛博地狱背景（取消十八层地狱方案）
- 鬼佛阶段背景切换为**赛博灵山**（金色灵山 + 赛博祥云 + 宝刹佛光，与地狱段形成"劫→渡"反差）

### 4.4 音效

- WebAudio 实时合成，无素材文件：木鱼"咚"（赛博混音）、迸裂炸裂声、功德飘字"up"音、升级金光轰鸣

## 5. 存档与离线

- localStorage 自动存档：木鱼等级、功德、宠物（等级/存活）、图鉴点亮、皮肤持有（木鱼皮/鬼物皮试用与永久）、签到天数/连续签到、累计广告观看次数、周目数
- **离线惩罚**：退出后每小时消耗一定功德 + 木鱼等级向下掉（`Date.now()` 差值计算）；总功德**锁死最低 1 点**；回归弹"离线结算"卡
- 存档损坏兜底：字段异常 → 重置新档但保留图鉴

## 6. 技术架构（HTML5 原型 → 移植 Cocos Creator 3.x）

### 6.1 原型形态

单页 HTML5：原生 Canvas 2D + WebAudio，零依赖零构建，浏览器直接打开即玩；以组件式思维书写保证移植 Cocos 时 1:1 平移逻辑层。

### 6.2 模块划分

| 模块 | 职责 |
|---|---|
| `GameCore` | 主循环（update/render）、全局调度 |
| `GameState` | 功德/木鱼等级/宠物/皮肤/图鉴/存档单一数据源 |
| `TapSystem` | 点击木鱼判定、功德增加、电流特效触发 |
| `GhostManager` | 鬼物波次生成、9 级配置表、赛博进化、向金光移动/AI |
| `PetSystem` | 2 猫 + 4 鹦鹉解锁/升级/自动索敌攻击 |
| `ShieldSystem` | 金光罩强度、被啃食、消失→宠物替死→重开 |
| `FxSystem` | 粒子：金光圈、电弧、赛博烟花（1/3 屏）、功德飘字 |
| `HUD & Skins` | 功德条、签到、皮肤兑换、图鉴、广告（模拟） |
| `AudioEngine` | WebAudio 合成木鱼/爆炸/飘字音效 |
| `SaveManager` | localStorage 自动存档 + 离线惩罚计算 |
| `AdProvider` | 激励视频抽象接口（原型模拟，发布接抖音 SDK） |

### 6.3 抖音小游戏对接

- 竖屏适配：基准逻辑分辨率 432×768，自适应任意竖屏比例
- `TTSDK` 适配层：发布时替换 `AdProvider` 为 `tt.createRewardedVideoAd()`、体检分/转发等抖音能力预留接口

## 7. 实现范围（原型 MVP）

**MVP 包含**：核心循环（敲木鱼→金光→鬼潮→烟花）、功德条与升级、宠物自动协战与替死、重开与图鉴、签到与皮肤（木鱼皮/鬼物皮试用与永久）、广告模拟（复活+皮肤）、离线惩罚、存档。

**MVP 不包含**（预留）：真实抖音 SDK 接入、周目 2/赛博鬼佛完整数值、新鬼物皮肤扩展池、音效音乐资源文件化。
